## 🚀 Projects

### 📱 MPTI (My Personal Todo Indicator) — Android Project
사용자의 성향(MBTI 등)과 맥락을 분석하여 개인 맞춤형 할 일 관리 및 마일스톤 가이드를 제공하는 안드로이드 애플리케이션입니다.
* **주요 특징**
  * **맞춤형 UX/UI:** 가벼운 투두 관리와 핵심 마감일정(Milestone)을 구조적으로 분리하여 시각적 피로 최소화
  * **맥락 중심 계층 설계:** 카테고리 ➔ 마일스톤 ➔ 태스크로 이어지는 3단계 계층 구조를 구현하여 다음 행동 흐름 제공

### 🎓 장학금 자동 매칭 웹 서비스 (`yna_prj_springboot`)
사용자의 학적 상태, 학점, 소득분위 등을 기반으로 조건에 딱 맞는 장학금을 판별하고 추천해 주는 3계층(Frontend-Backend-Database) 구조의 웹 서비스입니다.
* **주요 역할 & 특징**
  * **전 과정 단독 수행:** 서비스 기획, DB 모델링, REST API 구현, 배포 환경 구성까지 풀스택 프로세스를 단독 경험
  * **React 기반 Frontend:** 포트 9000 번에서 실행되는 깔끔한 사용자 인터페이스 구성
  * **대용량 데이터 처리:** 한국장학재단 CSV 공공데이터 파싱 및 자동 데이터베이스 저장 로직 구현
